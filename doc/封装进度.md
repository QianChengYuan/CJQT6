## 信号与槽 ✅

### 回调类型定义

```cangjie
// 无参数回调
public type VoidCallback = CFunc<() -> Unit>

// Int32参数回调
public type Int32Callback = CFunc<(Int32) -> Unit>

// CString参数回调
public type CStringCallback = CFunc<(CString) -> Unit>
```

### 支持信号的控件

| 控件 | 信号 | 方法 | 回调类型 |
|------|------|------|----------|
| QPushButton | clicked | setOnClick(callback) | VoidCallback |
| QLineEdit | textChanged | setOnTextChanged(callback) | CStringCallback |
| QSpinBox | valueChanged | setOnValueChanged(callback) | Int32Callback |
| QSlider | valueChanged | setOnValueChanged(callback) | Int32Callback |
| QCheckBox | stateChanged | setOnStateChanged(callback) | Int32Callback |
| QRadioButton | toggled | setOnToggled(callback) | VoidCallback |
| QComboBox | currentIndexChanged | setOnCurrentIndexChanged(callback) | Int32Callback |
| QAction | triggered | setOnTriggered(callback) | VoidCallback |
| QTimer | timeout | setTimeout(callback) | VoidCallback |

### 断开信号连接

所有支持信号的控件都提供了 `disconnect()` 方法：

```cangjie
// 断开信号连接
button.disconnect()
slider.disconnect()
timer.disconnect()
```

### 使用示例

```cangjie
// 按钮点击
let buttonCallback: VoidCallback = { =>
    println("按钮被点击！")
}
button.setOnClick(buttonCallback)

// 滑块值变化
let sliderCallback: Int32Callback = { value: Int32 =>
    println("滑块值: ${value}")
}
slider.setOnValueChanged(sliderCallback)

// 文本变化
let textCallback: CStringCallback = { text: CString =>
    println("文本: ${text}")
}
lineEdit.setOnTextChanged(textCallback)
```
