# CJQT6 音乐播放器

基于仓颉语言和 Qt6 开发的本地音乐播放器，模仿千千静听经典风格。

## 功能特性

### 播放控制
- **播放/暂停** - 点击播放按钮或按空格键
- **停止** - 停止当前播放
- **上一曲/下一曲** - 切换播放列表中的歌曲
- **进度条** - 拖动跳转到指定位置
- **播放速度** - 支持 0.5x ~ 2.0x 变速播放

### 播放模式
- **顺序播放** - 按列表顺序播放
- **列表循环** - 播放完毕后从头开始
- **单曲循环** - 重复播放当前歌曲
- **随机播放** - 随机选择下一首

### 音量控制
- 音量滑块调节 (0-100%)
- 一键静音/取消静音

### 播放列表
- 添加文件 - 支持多选
- 添加文件夹 - 自动扫描音频文件
- 移除选中项
- 清空列表
- 双击列表项播放

### 支持的音频格式
- MP3
- WAV
- FLAC
- OGG
- M4A
- AAC
- WMA

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Space` | 播放/暂停 |
| `Ctrl+O` | 添加文件 |
| `Ctrl+Shift+O` | 添加文件夹 |
| `Left` | 上一曲 |
| `Right` | 下一曲 |
| `Ctrl+S` | 停止 |
| `Ctrl+M` | 切换播放模式 |
| `Ctrl+R` | 切换播放速度 |
| `Alt+F4` | 退出 |

## 自定义图标

### 使用方法
1. 准备图标文件（PNG 格式，建议 24x24 或 32x32 像素）
2. 菜单 → 设置 → 图标文件夹... → 选择图标所在目录
3. 图标会自动加载

### 图标文件命名

| 文件名 | 用途 |
|--------|------|
| `prev.png` | 上一曲按钮 |
| `play.png` | 播放按钮 |
| `pause.png` | 暂停按钮 |
| `stop.png` | 停止按钮 |
| `next.png` | 下一曲按钮 |
| `mute.png` | 静音按钮 |

### 恢复默认图标
菜单 → 设置 → 重置为标准图标

## 编译运行

### 依赖
- 仓颉编译器 1.0.5+
- Qt 6.4+ (Multimedia 模块)
- Windows: MinGW 或 MSVC

### 编译
```bash
cd examples/music_player
cjpm build
```

### 运行
```bash
# Windows
cd target/release/bin
./main.exe

# Linux
cd target/release/bin
./main
```

### 关键类
- `QMediaPlayer` - 媒体播放器
- `QAudioOutput` - 音频输出
- `QSlider` - 进度条/音量滑块
- `QListWidget` - 播放列表
- `QPushButton` - 控制按钮
